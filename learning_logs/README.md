# Learning Log (学习笔记) - Django Practice

记录我的 Python Web 开发学习历程，基于《Python编程：从入门到实践》第18章构建。

## 📖 项目简介
这是一个基于 Django 的 Web 应用，用于记录学习笔记。用户可以创建感兴趣的主题（Topic），并在每个主题下添加具体的日志条目（Entry）。

## 🛠️ 技术栈
- **Backend**: Python 3.14, Django 6.1.1
- **Database**: SQLite3
- **Frontend**: HTML5 (基础模板), CSS (正在学习)
- **Version Control**: Git & GitHub
